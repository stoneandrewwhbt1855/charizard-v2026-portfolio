The project is primarily composed of HTML, so most changes are made within the markup, asset paths, and written content in the source files.

Example structure:

      "siteTitle": "charizard",
      "sections": ["branding", "social media", "logo design"],
      "assetsPath": "./assets/"
    }

To change the page arrangement or establish a new visual hierarchy, edit the HTML structure and its linked media files directly.

## Frequently Asked Questions

**How can I replace the portfolio material?**  
Modify the HTML files, then swap the existing copy and visuals for your own design projects.

**Where do I make configuration changes?**  
The main adjustments are made in the project files, particularly the HTML and the references to media assets.

**Is local viewing supported?**  
Yes. You can open the site directly in a browser or serve it through a local server for previewing.

**What is the best way to keep the site updated?**  
Add recent projects, revise descriptions, and replace older screenshots or mockups as your body of work develops.

**What should I check when the browser rendering is incorrect?**  
Review the HTML structure, image dimensions, and file paths. You can also compare the result in another browser to identify rendering differences.
